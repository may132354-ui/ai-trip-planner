AI旅行プラン作成アプリの開発

1. 始めたきっかけ

私は旅行が好きで、旅行の計画を立てるときに、観光地や交通手段などを一つずつ調べるのに時間がかかると感じていました。そこで、AIを活用して、旅行先や予算、日程などの条件を入力するだけで、自動的に旅行プランを作成できるアプリを開発したいと考えました。

2. 自分で調べて試したこと

専門学校のグループ制作で、React、Spring Boot、Gemini API、MySQL、Dockerを使用して、AI旅行プラン作成アプリを開発しました。

Reactで入力画面を作成し、Spring Bootを通してGemini APIに情報を送信する仕組みを実装しました。また、生成した旅行プランをMySQLに保存し、後から確認できる機能も作成しました。

開発中には、Dockerのポート設定などでエラーが発生しましたが、エラーメッセージを確認し、インターネットで調べながら設定を修正しました。

3. 試した結果と効果

旅行先、日程、予算、興味のあることを入力すると、AIが条件に合わせた旅行プランを自動生成できるようになりました。

これにより、旅行計画を一から考える手間を減らすことができました。また、作成したプランを保存して再確認できるため、同じ内容を何度も入力する必要がなくなりました。

4. 学んだこと

今回の開発を通して、複数の技術を連携させて一つのアプリを作る方法を学びました。また、エラーが発生した際には、すぐに諦めず、自分で原因を調べて試すことの大切さを実感しました。
